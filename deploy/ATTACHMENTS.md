# 业务附件

合同（新建、草稿及编辑）、开票资料、发票和回款票据共用多附件组件，可连续添加、多选及移除已选文件，不设置业务上的数量、格式或文件大小上限。原文件逐字节保存，不压缩图片。

浏览器逐个文件上传，每个文件拆为 4 MiB 传输块；文件总大小不受单次 HTTP 请求上限影响。分块校验 SHA-256，失败回退到上一块，丢失响应可安全重发，界面提供进度和重试。附件上传成功后，表单提交签名引用。引用绑定当前用户和附件类别，有效期 24 小时，未完成文件不能提交。

不修改数据库结构。一个附件继续使用原来的 URL 字段；多个附件在 UPLOAD_DIR 下保存 `<UUID>.attachments.json` 清单，数据库原 URL 字段指向 `/attachments/<类别>/<UUID>`。附件列表页面及订单、财务页面解析清单显示所有文件。编辑旧订单时会加载原附件，可保留、追加或移除。移除仅改变订单引用，不删除磁盘原文件。

备份时应包含整个 UPLOAD_DIR（包括清单）和数据库；恢复时两者一起恢复。新代码兼容已有的单附件记录。更新仅部署应用，禁止执行数据库重建、种子数据或结构迁移。

头像、品牌 Logo 和结构化数据导入使用各自的图片/表格处理流程，不属于业务附件。
